# Security

Report a vulnerability in this starter, the Petiole API or the platform
privately:

- with GitHub's **Report a vulnerability** on this repository's Security
  tab, or
- by email to support@petioleapp.com, with "Security" in the subject.

We answer within three working days. Do not disclose the issue publicly
before it is fixed.

If you exposed an API key, revoke it at once on Keys & access in the
Petiole platform and make another: a revoked key is refused within a
minute.
